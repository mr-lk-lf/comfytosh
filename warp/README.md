# Comfytosh for Warp

The [Comfytosh Theme](../README.md) port for [Warp](https://www.warp.dev), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Save the files in `~/.warp/themes/` (Linux and macOS), then choose the theme in Settings, Appearance, Themes.

## Files

- [`comfytosh-screen.yaml`](comfytosh-screen.yaml)
- [`comfytosh-case.yaml`](comfytosh-case.yaml)
