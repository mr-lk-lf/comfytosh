# Comfytosh for tmux

The [Comfytosh Theme](../README.md) port for [tmux](https://github.com/tmux/tmux), in both flavors: **Comfytosh Screen** (dark) and **Comfytosh Case** (light).

## Install

Save the files somewhere in your config and add `source-file ~/.config/tmux/comfytosh-screen.conf` to `tmux.conf`.

## Files

- [`comfytosh-screen.conf`](comfytosh-screen.conf)
- [`comfytosh-case.conf`](comfytosh-case.conf)
