Make a port

Comfytosh is open in the way Catppuccin and Dracula are: anyone can bring it to the tool they love. A port is a folder with both flavors, a README and a line in ports.json.

  1. Claim it. Search the issues, then open a port request so nobody builds it twice.
  2. Copy the template. template/ becomes <your-tool>/, named the way the tool is.
  3. Use the roles. Map the app to the roles in palette.json, never to raw hex you picked by eye.
  4. Ship both flavors. Comfytosh Screen and Comfytosh Case, with a screenshot of each.
  5. Check and open a pull request. python3 scripts/check_ports.py runs in CI too.
